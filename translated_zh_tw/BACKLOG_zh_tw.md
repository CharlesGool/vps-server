# 待辦清單

[English](../BACKLOG.md) | **繁體中文**

> 譯自 `BACKLOG.md`（v1.0.0）。如有衝突，以英文版為準。

需求清單。所有被提出的要求，最重要的排最前面，完成後打勾。這是在間隔兩週後回來要回答「接下來該做什麼？」時要看的檔案，也是一個工作階段結束時、仍有工作留在檯面上時，需求要被寫進去的地方。

**`STATUS.md` 的 `Next:` 欄位，就是這裡最上面那個尚未打勾的項目，逐字複製過去。** 那一步完成時，在這裡打勾，並把下一個尚未打勾的項目提到 `Next` 那裡。這兩者絕不能不一致：`Next` 是跨專案總表顯示的那一行，而這份檔案才是實際續接工作時要讀的內容。

每個項目都帶著加入的日期，這樣一年前就開著的項目一眼就能看出是陳舊的，而不會悄悄變成永久項目：

```
- [ ] YYYY-MM-DD <要做什麼> — <從哪裡開始：檔案、指令，或懸而未決的問題>
- [x] YYYY-MM-DD <已完成的一項>
```

寫項目時要讓它能被冷啟動：「改善錯誤處理」是一則筆記，不是待辦項目；「把 mount 呼叫包進重試機制 — `src/mount.py`，底部那個空的 except」才是。
