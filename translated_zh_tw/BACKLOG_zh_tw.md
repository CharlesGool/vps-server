# Backlog

> 本文件按規則只在打 tag 時重譯，因此兩次發版之間它滯後於英文版——**要動手做事情
> 請讀 `BACKLOG.md`。**

需求清單。使用者提過的每一件事都記在這裡，重要的在前，做完打勾。隔兩週回來，「我下一步
要做什麼」由這份文件回答；一次會話結束時手上還沒做完的需求，也落在這裡。

**`STATUS.md` 的 `Next:` 欄位是這份清單裡最上面那條沒打勾的，逐字抄過去。** 那一步
做完就在這裡打勾，並把下一條沒打勾的提上去。兩處不允許不一致：`Next` 是跨專案總表
顯示的那一行，而真正接續時讀的是這份文件。

每條都帶加入日期，好讓掛了一年還沒打勾的條目顯眼，而不是悄悄變成常駐：

```
- [ ] YYYY-MM-DD <要做什麼> — <從哪兒下手：檔案、指令，或那個待定的問題>
- [x] YYYY-MM-DD <已完成的一條>
```

條目要寫到冷啟動也能開工。「改善錯誤處理」是一句備忘，不是 backlog 條目；「給掛載呼叫
加重試 —— src/mount.py 底部那個裸 except」才是。
