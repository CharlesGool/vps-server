## v1.0.0 — 2026-09-12

首次發布。本專案整合了兩個既有專案——一個帶密碼保護的 VPS 測速控制台，以及一個
sing-box `anytls` 安裝程式——並新增了兩者原本都沒有的兩項能力：一個隨需開啟的
iperf3 時間窗，以及一個公開頁面，讓任何人都能檢查你的 IP 在網路上是否有回應。

### Added

- **80 和 443 埠上的公開可達性頁面，無需登入。** 把 IP 給任何人；只要頁面能渲染
  出來，就表示你的 web 埠從對方所在的位置是可達的。頁面會回報對方的來源位址、
  伺服器時鐘，以及對方是從哪個埠、哪種協定進來的——除此之外不透露主機的任何
  其他資訊。同時服務兩個埠是刻意設計的：這樣才能區分「主機不可達」和
  「specifically 443 被擋住了」這兩種情況。
- **隨需開啟的 iperf3 時間窗。** 控制台會開啟一個有時限的時間窗；`iperf3`
  只在窗口期間執行，會在目前生效的防火牆上開放對應埠，並在窗口到期時——不論是
  應要求關閉，還是服務本身停止——把兩者一併關掉。沒有「一直開著」這個選項，
  因為一台常駐的 iperf3 伺服器會讓任何陌生人跑滿你的上行頻寬。窗口開啟期間，
  公開頁面會顯示這個訊息，讓測試者知道何時可以連線。
- **瀏覽器測速與訪問記錄**，皆在控制台內提供：使用 LibreSpeed 引擎進行的上傳/
  下載測速，以及從核心連線表讀取的、任意埠上每一筆連入 TCP 連線的記錄——不只
  限於 HTTP。
- **anytls 代理模組。** 搭配自簽憑證的 sing-box，並啟用 BBR。控制台會顯示節點
  的埠、密碼與 SNI，提供附一鍵複製按鈕的 Clash 設定條目與 `anytls://` 連結，並
  可以輪換認證資訊。
- **可選模組的安裝程式。** web、iperf3 與 anytls 各自獨立選擇，可互動式選擇，也
  可透過 `VPSSRV_MODULES` 用於無人值守安裝。遇到埠已被其他程序占用時會選擇拒絕
  安裝，而不是硬搶；在非 x86-64 架構上則會跳過 anytls，而不是安裝一個根本跑不
  起來的執行檔。
- **可感知既有安裝的重新安裝。** 重新執行安裝程式時會偵測到既有安裝，提供保留
  其設定的選項，重放記錄在 service unit 中的設定值，保留 anytls 節點的認證資訊，
  並只詢問既安裝版本當初沒有的那些設定項。早於這套記錄機制的舊安裝，則透過讀取
  磁碟上的模組清單來處理。
- **三種介面語言**——英文、簡體中文、繁體中文——在安裝時選擇，之後每次造訪皆可
  切換，並會記住選擇。
- **離線安裝。** sing-box 執行檔隨程式碼庫一併提供，因此安裝除了發行版自身的套件
  鏡像來源之外，不需要任何其他東西。

### Notes

- 整個專案採用 GPL-3.0 授權，因為它重新散布了採用 GPL-3.0 授權的 sing-box
  執行檔。各元件的授權條款以及 GPL 要求提供的對應原始碼連結，都列在
  `THIRD_PARTY_NOTICES.md` 中。
- 443 上的 TLS 是自簽憑證：沒有網域，也沒有 ACME。瀏覽器發出警告仍然能證明該埠
  有回應，而這正是那個頁面存在的目的所要解決的問題。
- iperf3 JSON 輸出中的 `mean_rtt` 來自核心的 `TCP_INFO`，因此 Linux 用戶端會回報
  往返時間，而讀不到這項資訊的用戶端——例如在 Windows 上透過 Cygwin 執行的
  iperf3——就只會回報傳輸量。UDP 模式（`-u`）在任何情況下都能提供抖動與丟包率
  資訊。
- anytls 模組僅支援 x86-64。web 與 iperf3 模組則與架構無關。
