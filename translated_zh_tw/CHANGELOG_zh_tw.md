## v1.0.0 — 2026-09-12

首次發布。本專案整合了兩個既有專案——一個受密碼保護的 VPS 測速主控台，以及一個
sing-box `anytls` 安裝程式——並新增了兩者都沒有的兩項能力：一個隨需開啟的 iperf3
視窗，以及一個讓任何人都能檢查你的 IP 是否能在網路上被連通的公開頁面。

### Added

- **80 與 443 埠的公開連通性頁面，無需登入。** 把 IP 交給任何人；只要頁面能渲染出來，
  就代表你的網頁埠從對方所在的位置是可連通的。頁面會回報對方的來源位址、伺服器時鐘，
  以及對方是從哪個埠、哪種協定連進來的——除此之外不透露主機的任何其他資訊。同時提供
  兩個埠是刻意設計：這樣才能區分「主機整體不可連通」和「443 特別被擋」這兩種情況。
- **隨需開啟的 iperf3 視窗。** 主控台會開啟一個限時的時間窗口；`iperf3` 只在窗口內運行，
  會在當前啟用的防火牆上開放對應埠，並在窗口到期時——無論是因為使用者要求，還是服務
  停止——把兩者一併關閉。沒有「持續開著」這個選項，因為一台開放的 iperf3 伺服器，
  任何陌生人都能用它把上行頻寬跑滿。窗口開啟期間，公開頁面會顯示這個訊息，讓測試者
  知道何時可以連線。
- **瀏覽器測速與訪客紀錄**，皆位於主控台：使用 LibreSpeed 引擎進行上傳/下載測速，
  以及從核心連線表讀取的所有埠的每一筆進入 TCP 連線紀錄——不只是 HTTP。
- **anytls 代理模組。** 搭配自簽憑證的 sing-box，並啟用 BBR。主控台會顯示節點的埠、
  密碼與 SNI，提供其 Clash 設定項與 `anytls://` 連結並附有複製按鈕，也可以輪換憑證。
- **可選模組的安裝程式。** web、iperf3 與 anytls 可以互不影響地個別選擇，可透過互動
  方式，也可以透過 `VPSSRV_MODULES` 供無人值守安裝使用。當某個埠被其他行程占用時，
  安裝程式會拒絕安裝而不是硬搶；在非 x86-64 架構上會跳過 anytls，而不是安裝一個
  無法執行的二進位檔。
- **具升級意識的重新安裝。** 重新執行安裝程式時會偵測既有安裝，提供保留其設定的選項，
  重播記錄在服務單元中的設定值，保留 anytls 節點的憑證，且只詢問已安裝版本當初沒有的
  設定項目。早於這套記錄機制的舊安裝，則透過從磁碟讀取模組清單來處理。
- **三種介面語言**——英文、簡體中文、繁體中文——於安裝時選擇，每次造訪皆可切換，
  且會被記住。
- **離線安裝。** sing-box 的二進位檔已隨版本庫一併提供，因此安裝時除了你所用發行版
  的套件鏡像來源之外，不需要任何其他東西。

### Notes

- 整個專案採用 GPL-3.0 授權，因為它重新散布了 GPL-3.0 授權的 sing-box 二進位檔。
  各元件的授權條款，以及 GPL 要求提供的對應原始碼連結，都列在 `THIRD_PARTY_NOTICES.md`
  之中。
- 443 埠上的 TLS 是自簽憑證：沒有網域名稱，也沒有 ACME。瀏覽器出現警告訊息本身仍能
  證明該埠是可連通的，而這正是那個頁面存在的目的所在。
- iperf3 JSON 輸出中的 `mean_rtt` 來自核心的 `TCP_INFO`，所以 Linux 端會回報往返時間
  （round-trip time），而無法讀取此資訊的端點——例如在 Windows 上透過 Cygwin 執行的
  iperf3——則只會回報輸送量。UDP 模式（`-u`）在任何情況下都能提供抖動與遺失率資料。
- anytls 模組僅支援 x86-64。web 與 iperf3 模組則與架構無關。
