## 变更日志

### v5.8.0 — 2026-11-08

FRPS 加上与 Singbox 节点相同的流量统计和限制; 客户端证书改用随附的 OpenSSL, 修复旧版 openssl 主机生成无效证书颁发机构的问题. 升级命令不变, 配置和数据保留.

#### 新增

- **FRPS 流量统计和限制.** 与 Singbox 节点相同: 上传/下载用量, 流量配额(超出后限速到 1 Mbps 或封禁), 上下行限速, 有效期和重置周期, 配额按 `(上传 + 下载) × 2` 计入. 按 FRPS 的 bindPort 计量, 所有 frpc 隧道的流量都经过它. 在 FRPS 页面查看用量, 用"限制"对话框修改. 新服务 `vps-server-frps-meter` 负责计量, 计量失败时停止 FRPS. FRPS 模块因此需要 nftables: 离线版自带, 在线版缺少时由安装器用 apt 安装.
- **依赖最低版本检查.** 安装器在改动任何服务前检查 Bash 4.1, systemd 240, Python 使用的 SQLite 3.24 和 OpenSSL 库 1.1.1, `/usr/bin/python3` 3.9+ 和基础命令(flock, sha256sum, base64, getent, install, mktemp, systemd-run); 在线版还检查 CA 证书. 不满足时停止安装并说明缺什么.
- `python3 /root/apps/vps-server/src/web/client_cert.py check` 显示签发证书所用的 openssl 和证书颁发机构的自检结果.

#### 改进

- 客户端证书由安装包随附的静态 OpenSSL 3.5.9 LTS 签发, 使用项目自带的最小配置, 不再依赖主机 openssl 的版本和 openssl.cnf; 安装器不再用 apt 安装 openssl.
- 主机的 `ip`/`ss` 不支持 JSON 路由或 `-H` 时改用随附版本; 只在没有随附 iperf3 时使用主机 iperf3, 且须为 3.1+.

#### 修复

- 主机为 OpenSSL 1.1.1k 等旧版本时, 生成的客户端证书颁发机构重复写入 Basic Constraints, 连自身验证都不通过, 证书登录无法使用. 现在新的颁发机构须先在主机 TLS 库上通过一次双向 TLS 自检; 已有的无效颁发机构在下次签发证书时自动替换, 它签发的证书标为已撤销, 并关闭"要求客户端证书".
- FRPC 连接状态在只有随附 `ss` 的主机上始终显示未连接.
- README 离线安装的 `sha256sum -c SHA256SUMS` 只下载离线包时因缺少在线包而失败, 改为 `--ignore-missing`.

#### 验证

本机用 OpenSSL 1.1.1k 复现原问题并确认修复; Debian 11 容器(Python 3.9, libssl 1.1.1w)中依赖检查和证书签发通过. Debian 13 系统容器中离线版安装 web, proxy, frps: 服务全部运行, 经 HTTPS 操作控制台, FRPS 限制在内核规则中生效, 节点限制照常, 完全卸载无残留. 操作员在一台 VPS 上用 `v5.8.0-test.1` 原地升级, 确认证书签发与登录, FRPS 流量与配额限制正常. 未在主机 TLS 库为 OpenSSL 1.1.1k 的真机上验证, 未在真机实测 1 Mbps 限速速率. 修改 FRPS bindPort 后新端口最多约 2 秒未计量.

### v5.7.0 — 2026-11-08

加强控制台登录安全. 升级命令不变, 配置和数据保留; 升级时安装器会提示 4 个新的可选变量, 不填写即使用默认值. 新设置都在 设置 > 安全.

#### 新增

- **登录失败封禁开关.** 默认开启. 关闭后不封禁, 但照常记录每个 IP 的失败次数, 达到阈值时标记"已达阈值, 未封禁", 方便测试检测是否生效. 可以清除记录.
- **封禁逐次加长.** 同一 IP 一天内再次触发时, 封禁时长每次乘 10: 30 秒, 5 分钟, 50 分钟, 约 8 小时, 最长 24 小时(`VPSSRV_LOGIN_LOCKOUT_MAX_SECONDS`). 成功登录后清零.
- **IPv6 按 /64 计数和全局上限.** 同一 /64 网段的地址合并计数. 所有来源合计 60 秒内输错 20 次时, 从未成功登录过的地址暂停用密码登录 5 分钟(`VPSSRV_LOGIN_GLOBAL_MAX_ATTEMPTS`, `VPSSRV_LOGIN_GLOBAL_LOCKOUT_SECONDS`); 登录过的地址, 证书登录和 IP 免密登录不受影响.
- **控制台访问限制.** 默认关闭. 开启后只有列表中的 IP 或网段能连接控制台, 其他地址在 TLS 握手前就被断开. 当前连接不在列表中时不能开启, 也不能移除覆盖当前连接的项. 被挡在外面时以 root 运行 `python3 /root/apps/vps-server/src/web/console_access.py disable`, 不用重启.
- **登录设备.** 列出已登录的设备(浏览器, 系统, IP, 登录和最近活动时间), 可以让单台或其他所有设备退出. 闲置 2 小时自动退出(`VPSSRV_SESSION_IDLE_SECONDS`), 终端输入算作活动.
- **安全记录和 Bark 登录提醒.** 记录登录, 封禁, 打开 root 终端和安全设置变更, 页面显示最近 50 条. 填入 Bark 推送密钥后, 新地址首次登录和触发封禁时推送到手机; 密钥不在页面显示.

#### 改进

- 控制台响应带 Content-Security-Policy(只允许本站脚本), 并禁止被其他网站嵌入. 原内联脚本移到单独文件.

#### 修复

- 使用反向代理(`VPSSRV_TRUST_PROXY=1`)时, 客户端地址改取代理追加的最后一个 `X-Forwarded-For` 项, 客户端伪造的地址头不再影响限速, 日志和访问限制.
- 登录页的"使用证书登录"按钮与密码标签之间留出间距.
- README 的解压命令和安装器内部解压显式使用 `tar` 过滤器, 消除 Python 3.12 和 3.13 的 `DeprecationWarning`.

#### 验证

本机运行测试覆盖封禁, 开关, IPv6 合并, 全局暂停, 访问限制, 登录设备, 安全记录和用模拟服务器发送的 Bark 推送; 15 个页面在无头浏览器中没有 CSP 拦截. 操作员在局域网测试机上联网安装 `v5.7.0-test.1` 和 `v5.7.0-test.2`, 确认失败计数, 关闭时只标记, 开启时封禁和新排版正常. 尚未用真实 Bark 账号推送, 也未在真实反向代理后运行.

### v5.6.3 — 2026-11-06

**建议所有用户升级, 尤其是使用离线安装包的主机.** 升级命令不变, 配置和数据保留. 请通过 SSH 运行升级命令, 不要用控制台自带的终端.

#### 修复

- 离线包自带的系统运行库(nft, iptables, `ip`, `ss`)中的 pcre2 更新到 Debian 安全版本 10.46-1~deb13u3, 修复 JIT 栈分配过大的问题(GHSA-r9hj-j2rw-4q3m). 之前只从 Debian 主仓库取包, 漏掉了安全仓库; 其余 31 个包已逐个核对, 与 Debian 13 当前版本一致. 升级时自动替换已安装的运行库.
- 在控制台自带的终端里升级时, 屏幕上只显示一行 `Terminated`, 看不出安装是否还在进行. 现在会预先提示"控制台重启时终端会断开, 安装在后台继续", 并给出查看结果的命令; 进度显示被打断时也会说明安装仍在继续.
- 控制台重启不再卡住 90 秒: 关闭或重启时会正常挂断打开的终端.

#### 改进

- 生成客户端证书后, 页面改为四个步骤: 下载, 导入系统证书库(分别说明 Windows, macOS, Android, iOS, 以及 Firefox 需要单独导入), 完全退出并重开浏览器, 确认已使用证书后再开启"要求客户端证书". 安全设置在已有证书但当前连接没有出示时提示常见原因.

#### 内部维护

- 仓库不再提交 sing-box, frp, Lucky 和 Tailscale 等上游二进制; 构建离线包时按固定地址下载并逐个校验 SHA-256. 安装包内容不变. 源码安装会像在线版一样联网下载这些程序.

#### 验证

在一次性 Debian 13 容器中验证: 从 v5.6.2 升级, 分别在控制台终端所在的控制组内和普通 shell 中运行; 新运行库的 nft, iptables, `ip`, `ss` 可以运行; 从全新克隆构建的离线包与原包中的程序逐字节一致, 并装好代理模块运行. 证书导入步骤只检查了页面内容, 尚未在 macOS, Android, iOS 上实测.

### v5.6.0 — 2026-11-06

- 客户端证书登录. 在 设置 > 安全 > 客户端证书 中为每台设备生成 `.p12` 证书(导入密码只显示一次), 导入系统后浏览器用它登录, 不用密码; 证书可单独撤销, 服务器不保存设备私钥. 开启"要求客户端证书"后, 没有有效证书的设备只看到拦截页(指定 IP 免密登录同样需要证书), 密码只用于打开 root 终端和安全设置时的二次验证, Clash 订阅照常访问. 当前连接未出示证书时不能开启, 要求期间不能撤销当前使用的证书; 丢失证书时 root 执行 `python3 /root/apps/vps-server/src/web/client_cert.py disable` 恢复密码登录. 已在 Windows Chrome 上验证签发, 导入, 证书登录和开启要求.

### v5.5.0 — 2026-10-23

#### 新增

- Release 提供两个安装包. 离线版内置全部第三方程序和系统工具, 目标机不需要联网, curl, Git, tar 或 gzip, 只要 Python 3.9+. 在线版约 4 MB, 安装时按所选模块下载 Singbox, Lucky, FRP 和 Tailscale, 逐个校验 SHA-256, 主机缺少的 iptables, iproute2, nftables 由安装器用 apt 装好. 控制台之后添加 FRPC 或 Tailscale 模块时同样自动下载.

- 离线版的随附运行库新增 iproute2(`ss`, `ip`)及其依赖库. 主机没有这些命令时自动改用随附的, 不再弹出缺少 `ss` 或 `ip` 的警告.

- 安装开头的语言选择在 5 秒内没有回答就用默认值继续, 无人值守也能装完. 环境变量 `VPSSRV_PROMPT_TIMEOUT` 可改秒数, `0` 表示一直等待.

#### 变更

- 安装不再依赖 curl, tar 和 gzip: 一键安装命令, Tailscale 与 nftables 运行库的解压, 主机检查都改用 Python 自带的 tarfile 和 urllib. 精简镜像不用先手动装这些命令.

- 离线版安装包因随附 iproute2 及对应源码, 体积由约 98 MB 增至约 167 MB.

- 浏览器标签页标题的分隔符由长横杠 `—` 改为短横杠 `-`.

- 下载 Debian 软件包的构建脚本失败时自动重试.

### v5.4.0 — 2026-10-21

#### 新增

- 完整安装包随附 Debian 13 的 nftables 1.1.3 和 iptables 1.8.11, 连同 glibc 一起打包, 由自带的加载器运行. Debian 11+ 与 Ubuntu 20.04+ 主机没装 nftables 或 iptables, 或者断网时, 节点流量统计, 限速和端口转发也能用. 主机上能读取规则的版本仍然优先; 只装 Web 时也会放入这套运行库.

- 安装模块前检查主机条件: Singbox 需要可用的 nftables, Tailscale 需要 `/dev/net/tun` 且没有其他 tailscaled 在运行. 安装器, 控制台安装任务和未安装模块的卡片与安装页共用同一套检查; 不满足时在改动前停止, 显示原因和处理办法, 不再只显示"失败".

- 首次安装时安装命令留在前台跟随后台任务, 只显示关键步骤, 完成后显示控制台地址和初始密码; 失败时显示原因和几行相关日志. Ctrl-C 或 SSH 断开只停止显示, 安装继续.

- 功能页缺少模块时可直接安装, 并在原页面显示进度.

- 保存设置失败时用 Toast 提示 8 秒, 页面内不再重复显示同一错误.

#### 变更

- 全新安装的控制台默认使用 HTTPS 和自签名证书, 会话 Cookie 带 `Secure`; 升级保留原设置.

- 从控制台安装 Singbox, Lucky 或 Tailscale 时只安装所选模块, Web 和其他模块保持运行.

- 安装器在停止任何服务前检查 Python 版本(低于 3.9 时停止)和 iptables, `ss`, `ip`(缺少时警告并说明受影响的功能).

- 节点计量出错时, 日志附带 nft 自己的报错.

#### 修复

- 没有系统 nftables 的 Debian 13 主机上, 节点计量服务反复重启并停掉 Singbox: 旧的随附 nft 0.9.8 读不了新版 iptables-nft 写入的规则, 而安装预检只执行 `nft --version`, 因此没有拦下. 预检和运行时检查现在都实际读取规则表.

- 端口转发和 iperf3 表单缺少 CSRF 令牌, 同一主机其他端口上的页面可以代为提交.

- 浏览器预开的空闲连接会让 HTTPS 控制台和公开页停止响应: TLS 握手移到各连接的工作线程, 10 秒超时.

- 修改控制台端口时持锁重启 Web, 新进程释放 iperf3 残留端口登记超时后崩溃; 释放残留登记失败也不再阻止 Web 启动.

- 从控制台安装 Lucky 会停掉 Singbox; 卸载 Lucky 后页面不再提供安装按钮.

- 首次安装 Tailscale 失败后残留 unit 文件和程序, 回滚可能漏释放端口登记.

- 安装摘要中的公开页状态与控制台开关不一致; FRPS/Lucky 安装在已不存在的防火墙规则上失败并回滚; 代理配置文件权限改为 0600, BBR 改用独立的 sysctl 文件并在完全卸载时删除.

- 终端页和 FRPS, FRPC 未安装页使用了首页的标签页图标.

### v5.3.1 — 2026-10-07

#### 修复

- 用较短的 `VPSSRV_MODULES` 安装(如 README 快速安装)时丢失已安装模块, 并经节点计量依赖停掉 sing-box: 显式清单现在只追加模块, 磁盘上仍存在的模块重新计入.

- 公开页端口被其他进程占用时, 已有安装的所有安装和模块任务被中止: 现改为警告. 缺少前端构建产物时, 安装在写入任何内容前停止, 不再留下阻止后续安装的半成品状态目录.

- 卸载 Singbox 会删除全部节点: 现保留 sing-box 配置和节点清单, 只释放服务, 防火墙规则和端口登记; 重装时重新登记这些端口(端口已被占用则安全失败)并恢复防火墙规则. 卸载确认提示改为说明配置会保留.

- 重装 Lucky 因控制台刚关闭的连接处于 TIME_WAIT 而报"Address already in use": Lucky, FRPS 安装脚本以及节点, FRP, iperf3 的端口检查改用与服务相同的 `SO_REUSEADDR` 探测.

- 卸载 FRPC 会停掉所有实例, 重装后不再恢复: 卸载时记录已启用的实例, 重装后重新启用(整个 FRPC 分组已关闭时除外).

### v5.3.0 — 2026-10-07

#### 新增

- 共享界面组件: 顶栏与新增底栏(GitHub 主页, 项目仓库)在窗口缩放时逐项滑动; 设置页分区导航随滚动缓动跟随, 窄屏转为顶部条; 标签页图标随主题色及深浅色模式变化; 外观新增"跟随系统"; 服务器标识徽章可点击回到首页.

- Clash 二维码改为按钮加对话框; 卸载, 清空日志历史, 删除代理, 清除访客记录的二次确认改用控制台统一的对话框, 不再使用浏览器自带提示.

#### 变更

- Web 前端改用共享模板(Vue 3, Vite, TypeScript, Tailwind CSS): 统一设计标记, 八种主题色和响应式布局, 页面内容区与顶栏同宽对齐. 前端在 `web/` 构建, 完整安装包已含构建产物; 从源码安装需先在 `web/` 执行 `npm ci && npm run check`(Node.js 24).

- 顶栏左上角只显示项目名称, 不再显示标志(项目特例, 记录于 `doc/LOG.md`).

- 公网页(80/443)只返回一行纯文本"服务器看到你的 IP 地址".

- 刷新页面时先隐藏服务器渲染的回退布局, 待共享顶栏和自定义下拉就绪后再显示, 不再闪出旧布局或原生下拉.

- iPerf 3, Singbox, FRPS, FRPC, Lucky, Tailscale 与终端页面重新排版: iPerf 3 页面标题与"服务端""客户端"卡片, Singbox 统计块左对齐, FRPC 实例标题与新建按钮同行, 终端显示区放大且字号缩小. Lucky 管理页与首页 HTTP, HTTPS 卡片在新标签页打开. Tailscale 连接按钮并入同一行, 版本号只显示发行号, 路由和出口节点列表不再有"清除"项.

- 项目工具目录改用连字符命名(如 `tools/build-offline`), 新增统一静态检查 `tools/check-project`, CI 固定 Actions 版本; 安装命令不变.

#### 修复

- iperf3 安装与启停重启 Web 时与状态页请求竞争, 页面停在旧状态.

- 升级时安装器把刚关闭连接留下的 TIME_WAIT 套接字误判为 80/443 被占用而中止.

- Tailscale 连续点击"连接"失败: 同一时间只运行一次连接, 等待登录地址, 按钮点击后禁用(真机 Tailscale 工作正常, 操作员确认).

- 终端底部黑条, 模块关闭页空白卡片, 详细日志页返回控件指向错误, 页面图标重复.
