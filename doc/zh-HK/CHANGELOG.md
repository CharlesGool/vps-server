### v5.0.0 — 2026-10-03

#### 新增

- 控制台可向另一台 iperf3 伺服器發起有時限的 TCP 或 UDP 測試,並提供簡短的伺服器端及客戶端指令.
- 公開 HTTP 與 HTTPS 頁面有獨立開關和首頁入口;伺服器標識可持續儲存並顯示於導覽及瀏覽器標題.

#### 變更

- 首次安裝直接在終端完成,預設只安裝 Web 控制台;模組頁面可按需要安裝其他功能.FRPC 啟用狀態獨立於客戶端實例的運行狀態.
- Web 功能處理器與樣式按功能拆分,靜態資源歸入 `src/web/static/`;項目文件依簡體中文來源,歷史記錄,變更記錄及翻譯檔案整理.
- 一般 Web 服務重新啟動會保留未過期的登入會話;修改密碼仍會使舊會話失效.

#### 修復

- FRPC 實例名稱支援 Unicode 字母與數字;重新安裝模組會保留已安裝節點與服務狀態,並可在重新啟動前回報開關結果.
- 完整移除在刪除安裝目錄後,仍能列印本地化結束訊息並以成功狀態結束.

#### 驗證與限制

- 本地單元測試共運行 377 項,其中 369 項通過,8 項跳過;樣式建構,相依檔案校驗,項目結構,多語言及文件連結檢查通過.用戶報告先前各功能測試正常.本次原始碼結構遷移後尚未在真實主機重新安裝;重新啟動後的持久性,全部跨主機代理與轉發組合,以及真實流動裝置仍未全面驗證.
- FRPC 繼續使用先前正式版本的 [frpc-0.71.0-linux-amd64](https://github.com/CharlesGool/vps-server/releases/download/v4.0.0/frpc-0.71.0-linux-amd64) 資源,大小為 16,593,080 字節,SHA-256 為 `f79fff8de3089ec711ff8bdd4b73e00dfe491a1c3d754983c8b0f8d58c21b068`.離線安裝時將該檔案放在 `~/apps/vps-server/vendor/frp/frpc`,再從模組頁面安裝;安裝前會核對摘要.儲存庫保留的三個大型執行檔與 `v4.0.0` 的 Git blob 完全相同.

### v4.0.0 — 2026-09-29

#### 新增

- 通過帶一次性密碼的臨時 HTTPS 監聽器,在瀏覽器中完成首次設置,選擇模塊,語言,認證方式和端口.安裝後的控制枱可在 Settings 安裝或移除可選模塊,並顯示任務狀態和日誌.
- 可創建,重命名,編輯,啓用,停用,測試及刪除本機 FRPC 實例.編輯器支持簡單的令牌認證 TCP/UDP 代理,用 `frpc` 驗證修改,應用失敗時恢復舊配置.FRPC 可獨立於 FRPS 安裝;其帶固定校驗和的客户端二進制文件作為 `frpc-0.71.0-linux-amd64` Release 資源分發.
- Home 分別提供 FRPS 和 FRPC 入口及頁面.已停用功能的頁面會轉到本地化的“頁面已關閉”頁面.

#### 變更

- Home 將九項主要功能顯示為帶獨立開關的卡片.模塊管理移至普通 Settings;Security Settings 仍受最近一次管理員密碼驗證保護.
- FRPC 和代理節點卡片的編輯,測試,顯示及確認控件更加清楚.編輯實例時,未修改的服務器地址和令牌保持原值;代理字段區分本地端口與服務器端口.
- 登錄頁與 Settings 導航,頁面圖標,密碼控件,主題選項及響應式佈局遵循當前控制枱設計.正文使用系統字體,以維持刷新時的文字尺寸.根據操作員反饋移除頁面切換動畫;調整窗口大小時的動效仍保留.
- 端口轉發開關由運行中的 Web 進程協調規則,無需重啓控制枱.重複提交模塊操作會返回頁面;被拒絕的 POST 請求會正確關閉連接,避免把後續請求誤解析.

#### 修復

- 新增 FRPC 代理不再要求僅用於編輯或刪除代理的索引.功能停用時停止訪客採集;重新打開代理節點控件時保留已保存的值.

#### 驗證和限制

- 本地測試通過 341 項,跳過 8 項.指定測試機檢查了已登錄路徑,FRPS/FRPC 頁面分離,模塊開關,關閉頁面跳轉,FRPC 配置驗證,以及用户要求的指定遠端埠 TCP 代理.操作員認為當前刷新效果可以接受.測試機目前仍運行已打補丁的測試版本;發佈此正式源碼標籤本身不會升級該安裝.
- 真實移動設備,重啓後的持久性,從最終標籤在全新主機完整安裝,以及所有真實代理或轉發策略組合尚未驗證.此前發佈的三個大型可執行文件與 v3.0.0 相同.FRPC 客户端是新增的 16,593,080 字節 Release 資源,SHA-256 為 `f79fff8de3089ec711ff8bdd4b73e00dfe491a1c3d754983c8b0f8d58c21b068`;安裝程序在使用前驗證該摘要.

### v3.0.0 — 2026-09-28

#### 新增

- 可以單獨建立,編輯,停用,重置和刪除託管 AnyTLS,VMess,VLESS,Trojan 和 Shadowsocks 節點.顯示數字保持連續;隱藏的 UUID 保留身分.連接詳細資訊可以透過連結或二維碼複製或匯入到 Android 版 Clash Meta.
- 每個節點都會追蹤上傳和下載流量,並支援 GiB 上限,單獨的定向速度限制,按天,月或年重複重置以及可選的有效期.達到上限可以將兩個方向的速率限制為 1 Mbps 或阻止存取;過期的有效期會阻止存取.
- 明確的私有 IP 允許清單可以使用無密碼存取.在公開或更改憑證和存取規則之前,安全性設定需要最近檢查管理員密碼,包括僅限 IP 的會話.

#### 變更

- 統一控制台和登入佈局,響應式節點卡,儀表板導航和設定.普通設定現在提供八種持久的強調色和獨立的明/暗模式.儲存的憑證和配置的連接埠將被屏蔽,直到授權顯示或使用為止.
- iperf3 視圖將服務狀態與其可編輯連接埠分開.安裝程式升級保留執行階段 Web 入口點和暫存模組.代理設定摘要列出介面和可選的 Tailscale 位址,無需公共 IP 查找.修復了翻譯的文檔片段和第三方來源連結.

#### 驗證與限制

- 操作員報告功能測試已通過.本機套件通過了 311 項測試(跳過了 8 項);指定的測試主機為新的登入和主題資產提供服務,其中 Web,代理,節點流量計量服務和 AnyTLS 服務處於活動狀態並啟用啟動.在此版本準備過程中,並未獨立見證實際的重新啟動和每個即時策略傳輸.
- 未新增超過 10 MB 的新的或變更的 blob. 現有的 sing-box(57,995,520 位元組),frps(20,332,728 位元組)和 Lucky(10,883,644 位元組)可執行檔案具有與 `v2.0.0` 中相同的 Git blob ID; 出處和許可證記錄保留在 [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md) 中. frps 和 Lucky 仍處於試驗階段.

### v1.1.0 — 2026-09-19

### v1.0.0 — 2026-09-12

首個發佈版本.結合兩個現有項目——以密碼保護的 VPS 網速測試控制台,以及 sing-box `anytls` 安裝程式——並新增兩者原本都沒有的功能:按需開啟的 iperf3 時段,以及讓任何人檢查 IP 的網頁連接埠能否回應的公開頁面.

#### Added

- **公開連通性頁面於 80 及 443 提供,毋須登入.** 把 IP 交給對方;如能顯示頁面,代表對方所在位置能連到你的網頁連接埠.只顯示來源位址,伺服器時鐘和所用埠/協定,不透露其他主機資料.提供兩埠是刻意安排,以區分"主機無法連通"和"僅 443 被封鎖".
- **按需開啟 iperf3 時段.** 控制台開啟限時時段;`iperf3` 只在期間執行,在當前防火牆開放連接埠,到期,操作員要求或服務停止時一併關閉.沒有"持續執行"選項,因公開 iperf3 伺服器可供陌生人耗盡上傳頻寬.時段開啟時公開頁面會顯示,讓測試者知道何時連線.
- **瀏覽器網速測試及訪客紀錄**,由控制台提供:以 LibreSpeed 引擎量度上下載,並從核心連線表讀取任何連接埠(不限 HTTP)的每條入站 TCP 連線紀錄.
- **anytls 代理模組.** sing-box 使用自簽憑證及 BBR.控制台顯示節點連接埠,密碼及 SNI,提供 Clash 設定,可複製的 `anytls://` 連結,亦可更換憑證.
- **可選模組安裝程式.** web,iperf3,anytls 可互相獨立地互動選擇,或於無人值守運行時透過 `VPSSRV_MODULES` 指定.若其他程序佔用連接埠會拒絕而非爭用;非 x86-64 略過 anytls,不會安裝無法運行的執行檔.
- **了解升級的重新安裝.** 重跑安裝程式時偵測現有安裝,提供保留設定選項,重播服務單位所記錄設定,保留 anytls 節點憑證,只詢問舊版本未有的設定.早於這項記錄方式的安裝會從磁碟讀取模組清單.
- **三種介面語言**:英文,簡體中文,繁體中文;安裝時選用,可每次瀏覽切換並記住.
- **離線安裝.** sing-box 執行檔隨儲存庫提供,因此除發行版套件鏡像站外無須其他連線.

**發佈備註(v1.0.0):**

- 整個項目使用 GPL-3.0,因其再分發 GPL-3.0 sing-box 執行檔.組件授權及 GPL 要求的對應原始碼連結見 [THIRD_PARTY_NOTICES.md][local-link-007].
- 443 使用自簽憑證:沒有網域,沒有 ACME.瀏覽器警告已能證明連接埠回應,這正是頁面的目的.
- iperf3 JSON 輸出的 `mean_rtt` 來自核心 `TCP_INFO`,故 Linux 用戶端會報往返時間;不能讀取它的用戶端(例如 Windows 上 Cygwin 的 iperf3)只報吞吐量.UDP 模式(`-u`)在各平台提供抖動及遺失率.
- anytls 模組只支援 x86-64;web 和 iperf3 不受架構限制.
