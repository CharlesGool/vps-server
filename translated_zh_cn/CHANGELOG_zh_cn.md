## v1.0.0 — 2026-09-12

首个发布版本。它合并了两个已有项目——一个带密码保护的 VPS 测速控制台和一个
sing-box `anytls` 安装器——并新增了两者都不具备的两项能力：一个按需开启的
iperf3 窗口，以及一个让任何人都能检测你的 IP 是否在网络上可达的公开页面。

### Added

- **80 和 443 端口上的公开可达性页面，无需登录。** 把 IP 给别人；如果页面能
  渲染出来，就说明你的 web 端口从他们所在的位置是可达的。它会报告对方的来源
  地址、服务器时钟，以及对方是通过哪个端口和协议进来的——除此之外不会透露主
  机的任何其他信息。同时提供两个端口是刻意为之：这样能区分"整台主机不可达"
  和"443 端口被专门屏蔽"这两种情况。
- **按需开启的 iperf3 窗口。** 控制台会打开一个限定时长的窗口；`iperf3` 只在
  窗口内运行，会在当前生效的防火墙上打开对应端口，并在窗口到期时——无论是
  用户主动结束，还是服务停止——同时关闭两者。没有"一直开着"这个选项，因为一
  个常开的 iperf3 服务端会让任何陌生人都能把上行带宽跑满。窗口打开期间，公
  开页面会告知这一情况，测试者据此知道何时可以连接。
- **浏览器测速与访问记录**，均在控制台内：使用 LibreSpeed 引擎测量上传/下载
  速度，并记录所有入站 TCP 连接——不限于 HTTP——数据取自内核连接表，覆盖任
  意端口。
- **anytls 代理模块。** sing-box 配合自签名证书，外加 BBR。控制台会展示节点
  的端口、密码和 SNI，提供带复制按钮的 Clash 配置条目和 `anytls://` 链接，并
  支持轮换凭据。
- **可选模块的安装器。** web、iperf3 和 anytls 各自独立选择，可交互式选择，
  也可通过 `VPSSRV_MODULES` 用于无人值守运行。遇到端口已被其他进程占用时会
  拒绝安装而不是抢占，在非 x86-64 架构上会跳过 anytls 而不是安装一个跑不起来
  的二进制文件。
- **支持升级感知的重新安装。** 重新运行安装器会检测到已有安装，提供保留其配
  置的选项，重放记录在 service unit 里的设置，保留 anytls 节点的凭据，并且
  只询问已安装版本当初没有的那些设置项。对于早于这套记录机制的旧安装，则通
  过读取磁盘上的模块列表来处理。
- **三种界面语言**——英文、简体中文、繁体中文——在安装时选择，每次访问均可
  切换，并会被记住。
- **离线安装。** sing-box 二进制文件随仓库一同分发，因此安装除了发行版自带
  的软件包镜像源之外不需要其他任何东西。

### Notes

- 整个项目采用 GPL-3.0 许可，因为它重新分发了 GPL-3.0 许可的 sing-box 二进
  制文件。各组件的许可证以及 GPL 要求提供的对应源码链接，均在
  `THIRD_PARTY_NOTICES.md` 中列出。
- 443 端口上的 TLS 是自签名证书：没有域名，也没有 ACME。即便浏览器发出警
  告，也依然能证明该端口是可达的——而这正是该页面存在的意义所在。
- iperf3 JSON 输出中的 `mean_rtt` 取自内核的 `TCP_INFO`，所以 Linux 客户端能
  报告往返时延，而无法读取该信息的客户端——例如 Windows 上 Cygwin 环境下的
  iperf3——则只会报告吞吐量。UDP 模式（`-u`）在所有环境下都会给出抖动和丢包
  数据。
- anytls 模块仅支持 x86-64。web 和 iperf3 模块与架构无关。
